# 開發問題集

集中整理開發過程中遇到的問題、原因與解法，供後續查找與複習。

## 分類

| 分類 | 內容 |
|---|---|
| [TypeScript + TypeORM](./typescript-typeorm/) | Entity 欄位初始化、關聯映射、ESM metadata 與 migration 工作流程 |
| [API Contract Design](./api-contract-design/) | 錯誤碼型別設計、HTTP 狀態碼與回應格式慣例、PRD 與 API 文件一致性審查 |
| [Express + TypeScript](./express-typescript/) | 型別設計、Request 型別擴充、模組匯入路徑慣例 |

## 建議記錄格式

每筆問題盡量包含：

1. 問題現象或錯誤訊息
2. 發生原因
3. 解決方式
4. 容易混淆的觀念
5. 後續檢查清單
